# Глоссарий (корпусная мебель, БАЗИС)

- **ЛДСП** — ламинированная древесно-стружечная плита, основной материал корпуса (16 мм).
- **ХДФ** — древесноволокнистая плита (3 мм); задняя стенка, дно ящиков. В проекте — в пазе.
- **Кромка** — полоса материала на торцах панелей; клеится по периметру, защищает торец.
- **Конфирмат (евровинт)** — винт-стяжка 6×50 для соединения панелей под углом 90°.
- **Шкант** — деревянный/пластиковый цилиндрический шип для фиксации стыка.
- **Эксцентрик** — разборное соединение (эксцентрик + стяжка) для стыков.
- **Паз** — выбранный по контуру канал (например, 4×8 мм под ХДФ).
- **Фасад** — лицевая панель: дверь, фасад ящика.
- **Накладная дверь** — закрывает корпус снаружи, перекрывая торцы.
- **Вкладная дверь** — входит внутрь проёма корпуса.
- **Обвязка (обрамление)** — панели, обрамляющие блок ящиков; даёт зазор двери.
- **Антресоль** — верхнее отделение шкафа (полка под потолком).
- **Штанга** — труба для плечиков в вешалочном отделении; крепится штангодержателями.
- **Полкодержатель** — опора для съёмной полки.
- **Габаритная рамка** — служебный объект модели БАЗИС (общие габариты), не деталь.
- **Секция** — самостоятельный корпус шкафа; шкаф шире 1 м делится на секции.
