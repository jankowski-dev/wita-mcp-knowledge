# Roadmap: серия скиллов «Проектирование в БАЗИС»

> Статус: черновик плана (09.11.2026). Согласуется с пользователем, затем
> наполняется итерациями. Канон — этот файл + скиллы в `skills/`.

## Принципы

1. Скилл — **инструкция к действию**, не теория: формулы, таблицы размеров,
   правила, чек-листы, схемы присадки. Всё, что нельзя применить в задаче —
   не включаем.
2. Один скилл = одна зона ответственности. Дубли между скиллами запрещены —
   только ссылки.
3. Каждое правило проверяемо: либо сверяется с живой моделью/API (WITA MCP),
   либо с источником (ГОСТ/каталог производителя).
4. Пользовательские стандарты WITA (furniture-design) — выше общих правил из
   интернета. Источники из сети — фундамент, WITA — надстройка.
5. Скиллы описывают, что реально можно сделать в БАЗИС 2022 + worker; если
   операция недоступна — помечаем «вручную/после probe».

## Каталог скиллов (one-pager)

### 1. `materials-edging` — материалы и кромка (P1)
**Зачем:** каждый выбор материала/кромки влияет на габариты, прочность,
смету и карты раскроя.
**Содержание:**
- ЛДСП (16/18 мм, влагостойкая), МДФ, ХДФ 3 мм, фанера, массив, пластик;
  форматы плит (2750×1830 и др.), направление текстуры.
- Кромка: ПВХ 0.4/1/2 мм, ABS, лазерная; где какую (видимые торцы, полки,
  ящики, внутренние детали); влияние толщины кромки на размеры (±1–2 мм).
- Правила WITA (из furniture-design): ХДФ в пазе, кромка 2×35, исключения.
- Проверка через `list_materials` — какие материалы реально в базе.
**Источники:** каталоги Egger/Kronospan/Slotex, ГОСТ 16371 (материалы),
справочники по кромке.

### 2. `hardware-fasteners` — фурнитура, крепёж, присадка (P1)
**Зачем:** без точных схем присадки модель не сходится с производством.
**Содержание:**
- System 32: шаг 32, первый ряд 37 мм от торца, Ø5/Ø8, шканты, полкодержатели.
- Петли: чашка 35 мм, присадка 22–24 от края, ответная планка 32/37,
  накладные/вкладные/полунакладные, 110°/165°, доводчики.
- Направляющие: роликовые/шариковые (зазоры 13 мм/сторона), метабоксы,
  тандембоксы — посадочные размеры.
- Крепёж корпуса: конфирмат 6.4×50, эксцентрик, минификс, шкант+клей;
  где какой, порядок Mount (горизонталь первой и т.п. — из furniture-design).
- Ручки/газлифты/подъёмники: типовые схемы.
**Источники:** каталоги Hettich, Blum, Boyard, GTV; System 32 PDF; статьи
присадки; видео-разборы (для проверки цифр).

### 3. `kitchen-design` — кухни (P2 — под текущий проект)
**Зачем:** типовые модули и эргономика — база для генерации кухонь.
**Стандарт WITA (подтверждено):** с ПММ высота от пола **858** = цоколь 100 +
корпус 720 + столешница 38; без ПММ — ниже (уточнить точное значение).
**Содержание:**
- Нижний ярус: цоколь 100–150, корпус 720, столешница 28–40 → 850–900;
  высота под рост (таблица); глубина корпуса 550–560, столешница 600.
- Верхний ярус: высота 700–900, глубина 300–350, низ на 500–600 выше
  столешницы; антресоли.
- Пеналы 2100–2400×550–600.
- Техника: ПММ 600, духовка, варочная, вытяжка, холодильник; зазоры.
- Мойки/сушки/смесители; рабочий треугольник; зонирование.
- Фартук, столешница (свесы, примыкания), цоколь.
**Источники:** статьи эргономики кухонь, ГОСТ 13025.x (функциональные
размеры), каталоги кухонной фурнитуры.

### 4. `drawer-design` — ящики (P2/P3)
**Зачем:** ящик = корпус + направляющая + фасад — частый источник ошибок.
**Содержание:**
- Роликовые/шариковые: зазоры 13 мм на сторону, длина направляющей, расчёт
  корпуса; высота борта.
- Метабоксы (Hettich): посадочные размеры, зазоры, фасад.
- Тандембоксы/legrabox (Blum): номиналы 270–500, высоты M/N/K.
- Обвязка ящика WITA (дно в паз, корпус, фасад 596×236 — из текущего проекта).
- Схемы крепления направляющих (присадка System 32).
**Источники:** каталоги направляющих, статьи, текущие NOTES по ящикам.

### 5. `door-design` — двери, петли, фасады (P3)
**Зачем:** зазоры, схемы петель и вес фасада определяют работоспособность.
**Содержание:**
- Накладные/вкладные/полунакладные двери; угловые схемы (угол 90°, 135°).
- Зазоры 2–3 мм; расчёт ширины/высоты фасада; фальшпанели.
- Петли: количество по высоте/весу, чашка 35, присадка, регулировка.
- Газлифты/подъёмники для верхних шкафов; доводчики.
- Материалы фасадов: ЛДСП, МДФ фрезерованный, стекло/зеркало, алюминий.
**Источники:** каталоги петель (Hettich/Blum/GTV), таблицы нагрузок.

### 6. `wardrobe-design` — шкафы (P3)
**Зачем:** шкаф — вторая по частоте категория после кухни.
**Содержание:**
- Распашные и купе; глубина 550–600; высота до 2400+.
- Наполнение: штанги (высота установки), полки, ящики, антресоль,
  брючницы/обувницы.
- Раздвижные системы: расчёт дверей (перекрытие, ролики), профили.
- Угловые шкафы, примыкания, цоколь.
- Связь с `wardrobe-generator` (формулы генерации).
**Источники:** каталоги систем купе (Aris, Raumplus), статьи эргономики
хранения, ГОСТ 28102 (функциональные размеры шкафов).

### 7. `production-docs` — производство и документация (P4)
**Зачем:** проект без документации не изготавливается.
**Содержание:**
- Карты раскроя: оптимизация, направление текстуры, деление на листы.
- Кромление: карты кромки, порядок.
- Присадка: карты присадки, ЧПУ/сверлильные центры, шаблоны.
- Сборочные схемы, маркировка деталей, упаковка, транспортировка.
- Спецификация/смета: материалы, фурнитура, работы; СТП пользователя
  (спецификация по отступам/размерам — обсуждается отдельно).
**Источники:** БАЗИС-Смета/Раскрой документация, статьи производств.

### 8. `norms-gost` — нормативы (P4, справочный)
**Зачем:** проверка спорных решений, допуски и испытания.
**Содержание:**
- ГОСТ 16371-2014 (общие ТУ), ГОСТ 13025.1/.3/.4 (функциональные размеры),
  ГОСТ 28102 (корпусная мебель), ГОСТ 19917 (мебель для сидения — если
  понадобится).
- Допуски линейных размеров, зазоры, прочность/устойчивость, покрытия.
**Формат:** таблица «параметр → норматив → значение/ссылка».

## Фазы наполнения

- **Фаза 0 (сейчас):** согласовать каталог; инвентаризация существующего
  (5 скиллов + kb-источники); зафиксировать шаблон скилла.
- **Фаза 1:** `materials-edging` + `hardware-fasteners` — критично для СТП,
  генерации и проверки уже собранной кухни.
- **Фаза 2:** `kitchen-design` (текущий проект) + `drawer-design`.
- **Фаза 3:** `door-design` + `wardrobe-design`.
- **Фаза 4:** `production-docs` + `norms-gost`; наполнение каталогами
  производителей и текстами ГОСТов в `kb/sources/`.

## Процесс производства одного скилла

1. Собрать 3–5 источников (каталог/ГОСТ/статьи) → выжимка в `references/` или
   `kb/sources/`.
2. Черновик `SKILL.md`: таблицы, формулы, правила, чек-лист проверки.
3. Валидация с пользователем: 5–10 контрольных вопросов (стандарты WITA,
   используемые системы фурнитуры, допуски).
4. Проверка на практике: 1–2 задачи через WITA MCP (например,
   `list_materials`/`get_model_summary`); фиксация расхождений.
5. `npm run index` (KB), проверка `kb_search` по названию скилла.
6. Запись в AGENTS.md (таблица загрузки) + при необходимости DESIGN-RULES.md.

## Правила качества

- SKILL.md ≤ ~250 строк; детали — в `references/*.md`.
- Каждая цифра — с источником (или пометкой «стандарт WITA»).
- Источники датируются; устаревшие каталоги заменяем, не копим.
- Не включать: маркетинг, общий дизайн, «вдохновение» — только инженерия.
