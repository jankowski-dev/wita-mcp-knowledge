# Генератор шкафов — рецепт

Совмещай с `furniture-design` (правила), `basis-mcp` (операции) и
`bazis-grouping-rules` (блоки/имена/слои: `MOD_`, `FAS_`, без пробелов).

## Параметры

`W` ширина, `H` высота, `D` глубина, `t` толщина ЛДСП (16),
`N` секций (W > 1000 → N ≥ 2, секция ≈ 1200),
`comp` — отделений в секции (обычно 2),
состав: полки, ящики (3×250), штанги, двери (на каждое отделение).

## Формулы

Секция `s` (ширина `Sw`, смещение `sx`):

- Дно/верх: `Sw × D`, накладные, y = 0 и y = H − t.
- Боковины: `D × (H − 2t)`, x = sx и sx + Sw − t.
- Перегородка: `D × (H − 2t)` при `comp = 2`,
  x = sx + t + cw, где `cw = (Sw − 2t − t) / 2`.
- Полки: ширина `cw`, глубина `D`, y по составу (антресоль ~2000).
- ХДФ: `(Sw − 2t + 16) × (H − 2t + 16)`, z = 10 (паз 4×8, отступ 10), толщина 3.
- Ящики: блок 3×250 от y = t; фасад `cw − 2×16` шириной, утоплен на 16 по z.

Двери: ширина `(W − 2×2 − (n−1)×4) / n` (накладные), высота `H − 4`.

## Порядок операций (один батч на этап)

1. Демонтаж старого (если есть): `delete_object` по именам.
2. Панели корпуса → `add_panel` (orientation: front/horiz/vert; см. basis-engine
   про порядок аргументов).
3. Полки, ХДФ.
4. Кромка: `enable_butt_picker` + `add_butt` × 4 на каждую ЛДСП-панель.
5. Конфирматы: `open_furniture(Евровинт)` + `mount_furniture between` по стыкам
   (стойки↔дно/верх; полки — полка первой).
6. Фурнитура: петли `open_furniture(Петля для накладной двери)` + Mount
   (боковина, дверь, 32, y, 0); держатели/ручки — аналогично.
7. Проверка: `basis_model_summary` + визуальный скриншот.

## Проверка

- Count совпадает с ожидаемым (панели + крепёж + фурнитура).
- Кромка: `butts = 4` у ЛДСП-панелей и фасадов, 0 у ХДФ.
- Петли: 3 на дверь; у ящичных — выше блока (900/1650/2400).
- «Анализ модели» в БАЗИС — без ошибок.

## Известные грабли

- Перегородки ставятся на ЛЕВУЮ кромку проёма (иначе полки не достают 16 мм).
- Порядок Mount важен (см. basis-engine).
- Интерактивный пикер материала убивает сессию worker'а — не трогать руками.
