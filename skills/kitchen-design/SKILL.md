# Кухни — правила проектирования (WITA)

Дополняет `furniture-design` (конструктив корпуса), `hardware-fasteners`
(фурнитура/присадка), `drawer-design` (ящики), `bazis-grouping-rules`
(структура). Цифры ниже — стандарты WITA + практика; спорное помечено
**[ПРОВЕРИТЬ]**.

## 1. Высоты (главное)

| Параметр | Значение |
|---|---|
| Цоколь | **100 мм** (стандарт WITA) |
| Корпус нижних (с ПММ) | **720 мм** |
| Столешница | **38 мм** |
| **Итог с ПММ** | **858 мм** от пола (100+720+38) ✅ подтверждено |
| Без ПММ | по проекту WITA линия **та же 858** (в модели кухни столешница 820–858); вариант «ниже» не подтверждён — по умолчанию 858 |

- Встраиваемая ПММ 600 (высота 818) стоит **на полу**; верх 818 ≤ 858−38=820 —
  зазор 2 мм под столешницей. Соседние корпуса — 720 на цоколе.
- Верхний ярус (по модели WITA): низ на **1458** (зазор 600 от линии 858),
  корпус **720** (1458→2178), глубина **300**. Допускается высота 700–900,
  глубина 300–350.
- Пеналы: 2100–2400.

## 2. Габариты модулей

| Ярус | Глубина | Ширина | Высота |
|---|---|---|---|
| Нижний | корпус **550–560**, столешница 600 | 300–900 (тип 400/500/600/800/900) | 720 (с ПММ) |
| Верхний | **300 (тип WITA)** | 300–900 | **720 (тип WITA)**; 700–900 допустимо |
| Пенал | 550–600 | 400–600 | 2100–2400 |

- Секции длиннее 1 м делить (правило `furniture-design`).
- Зазоры фасадов: **2–3 мм** (в проекте WITA — 2/2).
- Столешница в модели — по габариту корпусов, **без кромки** (WITA).

## 3. Типовые модули

- База распашная (1–2 двери, полка).
- База с ящиками (2–3 ящика; см. `drawer-design`).
- База под мойку (без полки/со скрытой полкой, вырез в столешнице).
- База под варочную (усиление, вентиляция — по технике).
- Модуль ПММ (без дна/полок, крепление фасада к ПММ).
- Угловой модуль (карусель/слепой угол; стык столешниц).
- Пенал (духовка/микроволновка/хранение).
- Верхние: распашные, подъёмные (газлифт), открытые, сушка, антресоль.

## 4. Техника и мойки

- **ПММ**: 600 встраиваемая; рядом с мойкой (вода/слив); фасад на ПММ.
- **Духовка/микроволновка**: пенал; вентиляционный зазор по инструкции.
- **Варочная**: над ней вытяжка **650–750** до низа; защита столешницы.
- **Холодильник**: не у источника тепла; дверь открывается свободно.
- **Мойка**: чаша в столешнице, вырез по шаблону; смеситель — по центру/краю.
- **Сушка/мусорка**: модули 450–600 с направляющими AKS/GTV.

## 5. Столешница, фартук, цоколь

- Столешница 38 мм: вырезы под мойку/варочную; примыкания к стенам —
  планка/плинтус; **кромка не клеится** (WITA).
- Фартук: высота **600** от столешницы (зона 858→1458), без кромки.
- Цоколь 100: отдельная панель с плинтусом; зазор для ног.

## 6. Эргономика

- Рабочий треугольник: мойка–плита–холодильник; суммарные проходы
  минимум 1000–1200.
- Перед ПММ — ≥1100 свободного места; двери шкафов открываются свободно.
- Верхние шкафы: первая полка доступна без табурета (низ ≤1500).
- Розетки над столешницей (≈1100 от пола), вытяжка отдельно.

## 7. Сборка в WITA MCP

- Корпуса: `add_panel` по формулам `furniture-design` (верх/низ накладные,
  ХДФ в пазе, кромка 2×35).
- Крепёж: `open_furniture` + `mount_furniture`(between) — конфирматы через
  боковину в торец горизонтали; петли `Mount(боковина, дверь, 32, y, 0)`.
- Ящики: панели + направляющие (шариковые — основной вариант WITA).
- Кромка: `add_butt` полным именем материала (без пикера).
- Библиотеки: `Фурнитура\AKS\{Петли, Направляющие, Системы выдвижения}`
  (модели `.fr3d`), `Фурнитура\Петли\Петли AKS`.

## 8. Чек-лист кухни

1. Высота линии: 858 (с ПММ) / согласованная без ПММ.
2. Цоколь 100, столешница 38, фартук 600.
3. Глубины: 550–560 низ, 300–350 верх; столешница 600.
4. Зазоры фасадов 2–3; секции ≤1200.
5. ПММ на полу, верх 818, фасад по инструкции.
6. Вытяжка 650–750 над варочной; розетки/подсветка.
7. Мойка/смеситель/сушка/мусорка — по каталогам.
8. Материалы и кромка — по `materials-edging`; крепёж — по
   `hardware-fasteners`; имена — по `bazis-grouping-rules`.
