# Выдвижные ящики (WITA)

Дополняет `hardware-fasteners` (присадка/крепёж), `kitchen-design` (кухни),
`wardrobe-generator` (шкафы). Направляющие пользователя: **шариковые —
основной вариант; скрытые — GTV**.

## 1. Типы направляющих

| Тип | Зазор на сторону | Ход | Нагрузка | Примечание |
|---|---|---|---|---|
| **Шариковые (телескоп)** | **13 мм** (ящик = проём − 26) | полное | 25–45 кг | Основной вариант WITA |
| **Скрытые (undermount, GTV)** | по каталогу | полное | 25–40 кг | Дно в паз; плавный ход |
| Роликовые | ~12.5–13 мм | частичное/полное | 20–25 кг | Бюджет |

- Длина направляющей = **глубина корпуса − (10–20) мм**.
- Крепление к боковине — по System 32 / схеме производителя.
- Направляющие/системы AKS — в библиотеке
  `Фурнитура\AKS\Направляющие` и `Фурнитура\AKS\Системы выдвижения`.
- **Проверено по модели WITA (кухня B3):** проём 584 → внешняя ширина ящика
  **558** (зазор 13/сторона) — тип «шариковые» подтверждён; фасад 596×236,
  зазоры 2/2.

## 2. Расчёт корпуса ящика (шариковые)

- Ширина ящика (наружная) = **ширина проёма − 26 мм** (2×13).
- Глубина ящика = длина направляющей (ящик не длиннее направляющей).
- Зазор сзади — 10 мм от задней стенки корпуса.
- Высота борта — по фасаду/назначению (кухня — 236; шкаф — 250).

## 3. Корпус ящика WITA (из проекта кухни)

Состав (6 панелей): **Дно, Боковина L, Боковина R, Задняя, Передняя,
Фасад**.

- Дно — **[ПРОВЕРИТЬ: вкладное/накладное; паз или на саморезах]**;
  ХДФ/ЛДСП по стандарту проекта.
- Фасад — накладной, зазоры по фасадам **2/2** (кухня WITA).
- Боковины — между передней/задней или накладные — по принятой схеме
  **[ПРОВЕРИТЬ по эталону B3-D2 — снять контуры/позиции при следующем
  запуске worker'а]**. Эталон: ящик B3-D2 в проекте кухни WITA.
- Крепёж корпуса ящика — конфирмат/саморез по технологии; направляющие —
  саморезы по схеме.

## 4. Фасады ящиков

- Ширина фасада = ширина модуля − 4 (при зазорах 2/2), кухня 600 → **596**.
- Высота фасада = высота ящика − 4 (236 у кухни).
- Кромка — 2 мм на видимых торцах (см. `materials-edging`).
- Ручка/профиль — по дизайну; межцентровое по System 32.

## 5. Скрытые направляющие GTV (undermount)

- Посадочные размеры — по каталогу серии (глубина/высота корпуса ящика).
- Дно ящика — в паз (толщина по каталогу).
- Задняя стенка — с вырезом/по шаблону (если требует серия).
- Не путать с шариковыми: зазор/ширина корпуса другие — считать по
  каталогу, не по «26 мм».

## 6. Метабоксы и тандембоксы

- Метабоксы (GTV/AKS): металлические боковины; фасад по каталогу; зазоры
  по инструкции серии.
- Тандембоксы/legrabox (Blum): номиналы 270–500; высоты M/N/K; расчёт по
  каталогу Blum.
- Для кухни WITA основной путь — шариковые/скрытые; боксы — по запросу.

## 7. Присадка и сборка

- Направляющие шариковые: крепление по центру боковины ящика (ось —
  середина высоты борта) **[ПРОВЕРИТЬ по факту производства]**.
- System 32 — для полок/планок; отверстия направляющих — по шаблону.
- Порядок сборки: корпус ящика → направляющие → фасад → регулировка.

## 8. Чек-лист ящика

1. Тип направляющих выбран (шариковые/скрытые GTV) и длина = глубина − 10–20.
2. Ширина ящика = проём − 26 (шариковые) или по каталогу (undermount).
3. Зазоры фасадов 2/2; ширина/высота фасада − 4.
4. Корпус: 6 панелей по схеме WITA; дно/паз проверены.
5. Кромка: видимые торцы 2 мм, дно/ХДФ без кромки.
6. Крепёж и присадка — по `hardware-fasteners`.
7. Проверка хода/регулировки после сборки.
