# Материалы и кромка

Дополняет `furniture-design` (стандарты WITA — главнее). Технические факты —
из каталогов производителей и ГОСТ 16371-2014; спорные места помечены
**[ПРОВЕРИТЬ]** — уточняются у пользователя/производства.

## 1. Плитные материалы

| Материал | Толщины (мм) | Применение | Замечания |
|---|---|---|---|
| ЛДСП | 16 (стандарт), 18, реже 10/22/25 | Корпус, полки, фасады эконом | Влагостойкая (зелёный срез) — кухня, санузел; класс эмиссии E1 для жилья |
| МДФ | 10–22 | Фасады фрезерованные, эмаль, плёнка | Плотнее ЛДСП, лучше держит фрезеровку и кромку |
| ХДФ | 3–5 | Задние стенки, дно ящиков (в паз) | Кромкой не оклеивается (WITA) |
| Фанера | 4–21 | Эконом-корпус, выдвижные ящики | ФК — сухие помещения, ФСФ — влагостойкая |
| Массив/шпон | по породе | Премиум-фасады | Учитывать усадку/коробление |
| HPL/пластик | 1–2 (накладка) | Столешницы, фасады | Отдельный технологический цикл |

- Формат листа: типовой 2750×1830; у Egger встречается 2800×2070 —
  **[ПРОВЕРИТЬ]** по базе поставщика.
- **Текстура имеет направление** (древесный рисунок) — учитывать при раскрое
  и генерации: длинные детали ориентировать по текстуре.
- Влагостойкость обязательна для: кухня (зона мойки/плиты), санузел,
  стиральные машины.

## 2. Кромка

| Толщина | Материал | Где применять |
|---|---|---|
| 0.4–0.5 | ПВХ / меламин | Внутренние невидимые торцы, бюджетные серии |
| 0.8–1 | ПВХ | Универсальная корпусная мебель, полки, стенки |
| 2 | ПВХ / ABS | Фасады, столешницы, детская мебель, видимые торцы, кромка «под палец» |
| Лазерная (0 клей) | — | Премиум: монолитный торец, без шва |

- ABS экологичнее (без хлора), дороже; ПВХ — стандарт.
- Правило WITA (текущий проект): **кромка 2×35** на корпус; ХДФ не кромкуется;
  столешница/фартук/цоколь — **без кромки** (стандарт WITA).

## 3. Влияние кромки на габариты

- Готовый размер детали = габарит; пильный размер = готовый − толщина кромки
  на кромкованных сторонах. Т.е. кромка 2 мм «съедает» до 2 мм на сторону.
- В модели БАЗИС деталь задаётся **по готовому размеру** (контур), технология
  пересчитывает пил. Стыки/зазоры уже учитывают кромку.
- Толстая кромка (2 мм) на видимых торцах добавляет визуальный «поясок» —
  учитывать в примыканиях дверок/фасадов.

## 4. Связь с WITA MCP

- `list_materials` — реальный срез: материалы панелей, кромки (толщина×ширина),
  вырезы. Полные имена вида `H1399 ST10 …\r1355946` (с кодом) — использовать
  как есть, в т.ч. в `add_butt(material: "<полное имя>")`.
- `batch_set_material(dryRun: true)` — предпросмотр массовой замены.
- Назначение: `add_panel(materialName)`, `set_panel_material`.
- Если материала нет в базе — назначение молча не сработает; проверять
  readback и `list_materials`. Создание записей базы — только вручную в
  «Редакторе материалов» (API нет).

## 5. Чек-лист перед производством

1. Материал каждой детали есть в базе (`list_materials`) и совпадает по
   названию/коду.
2. Толщина соответствует узлу (корпус 16, фасад 16/18, ХДФ 3).
3. Кромка проставлена по сторонам; видимые торцы — 2 мм.
4. Текстура ориентирована; влагостойкость — во влажных зонах.
5. Форматы листов не превышены; детали влезают в раскрой.
6. Исключения WITA соблюдены (ХДФ без кромки и т.п.).
