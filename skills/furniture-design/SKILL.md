# Проектирование корпусной мебели — правила WITA

Применяй этот скилл при любой задаче: «сделай шкаф/тумбу/стеллаж», «проверь
конструкцию», «доработай проект». Технические детали операций — в скилле
`basis-mcp`; уроки движка — в `basis-engine`; формулы — в
`references/formulas.md`.

## 1. Членение

- Шкаф **длиннее 1 м делить на секции** (~1200 мм каждая). Секция — законченный
  корпус со своими боковинами; секции стоят рядом (двойная стенка в стыке).
- В каждой секции — 2 отделения (внутренняя перегородка).

## 2. Корпус

- **Верх и низ — накладные, одной деталью на секцию** (на всю ширину секции).
- Боковины и перегородки — **внутри**, между верхом и низом:
  высота = H − 2×толщина.
- Задняя стенка накладная **не делается**: ХДФ **в пазе**.
  Стандарт: паз 4×8 мм, отступ от задней кромки 10 мм; ХДФ 3 мм, кромкой не оклеивается.

## 3. Полки

- Крепление — **конфирмат через боковину/перегородку в торец полки** (горизонтально).
- Порядок панелей в Mount: **полка первой** (`Mount(полка, боковина, …)`) —
  иначе крепёж сядет на кромку, а не по центру толщины.
- В ящичных отделениях — полка над блоком ящиков.

## 4. Ящики

- Блок ящиков **обрамляется в корпус**; фасады ящиков **меньше** проёма на
  толщину обвязки (по 16 мм с каждой стороны) и **утоплены по глубине на 16 мм** —
  дверь не мешает выдвижению.
- Типовой блок: 3 ящика × 250 мм.
- Корпус ящика: боковины, дно, задняя и передняя стенки; фасад вкладной (зазоры 2 мм).
- **Петли в зоне обвязки ящичного блока на дверь не ставить.**

## 5. Двери

- По одной **накладной** двери на отделение.
- Зазоры: 4 мм между дверями, 2 мм по краям; толщина 16.
- Петли: `Mount(боковина, дверь, 32, высота, 0)` файлом **«Петля.f3d»**; чашка — в дверь.
- Сторона навески: крайние двери — наружу (левая — справа, правая — слева), средние —
  по схеме пользователя: для 5 блоков 1–3 — справа, 4–5 — слева.
  - вешалочные двери: 100 / 1250 / 2400 мм;
  - ящичные двери: только выше блока — 900 / 1650 / 2400 мм.

## 6. Кромка

- ЛДСП-панели — по периметру (4 стороны), материал по умолчанию из базы.
- Двери и фасады ящиков — по периметру.
- ХДФ — без кромки.
- Уточнения по внутренним деталям — в `references/checklist.md`.

## 7. Материалы и крепёж (по умолчанию)

- ЛДСП 16 мм — дефолт базы; ХДФ «ХДФ белая» 3 мм; кромка — дефолт базы.
- Крепёж — конфирмат («Евровинт 6х50»): корпусные стойки к дну/верху — через
  дно/верх в торец стойки; полки — через боковину в торец полки.

## 8. Порядок работы над проектом

1. Согласовать параметры: Ш×В×Г, число секций/отделений, состав (полки, ящики,
   штанги, двери), материалы, толщины.
2. Рассчитать панели по формулам (`references/formulas.md`) и **показать
   пользователю спецификацию до создания** (имена, размеры, количество).
3. Создать панели → кромка → крепёж → фурнитура (петли/держатели/ручки).
4. Проверить чтением модели (`basis_model_summary`, `object_info`) и отчитаться.

## 9. Чек-лист приёмки

- [ ] Секции > 1 м; верх/низ накладные одной деталью; стойки внутри.
- [ ] ХДФ в позиции паза, материал «ХДФ белая», без кромки.
- [ ] Кромка по периметру у всех ЛДСП-панелей и фасадов.
- [ ] Конфирматы: корпус — в торцы стоек; полки — через боковину в торец.
- [ ] Ящики: фасады уже проёма на 2×16, утоплены на 16; петли выше блока.
- [ ] Двери: зазоры 4/2, петли по схеме, чашка в двери.
- [ ] Проверка «Анализ модели» в БАЗИС — без ошибок.
