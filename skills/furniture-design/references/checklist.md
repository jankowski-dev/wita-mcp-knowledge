# Чек-лист приёмки проекта (расширенный)

## Корпус
- [ ] Секции: каждая > 1 м делится; стык секций — двойная стенка.
- [ ] Верх/низ — накладные одной деталью на секцию (перекрывают боковины).
- [ ] Боковины и перегородки внутри: H − 2×16.
- [ ] Перегородки ровно по проёмам (полки опираются на стенки без зазоров).
- [ ] Задняя стенка: ХДФ 3 мм «ХДФ белая», в позиции паза, без кромки.

## Кромка
- [ ] Все ЛДСП-панели: 4 стороны.
- [ ] Двери и фасады ящиков: 4 стороны.
- [ ] ХДФ: 0.
- [ ] Материал кромки — стандартный для проекта.

## Крепёж
- [ ] Стойки↔дно/верх: конфирмат через дно/верх в торец стойки (2 шт на стык).
- [ ] Полки: конфирмат через боковину в торец полки; полка первой в Mount.
- [ ] Петли: 3 на дверь, чашка в дверь; у ящичных дверей — выше блока.
- [ ] Нет крепежа в пустоте (проверить визуально, что полки достают до перегородок).

## Ящики
- [ ] Фасад = проём − 2×16 (обвязка), утоплен по глубине на 16.
- [ ] Зазоры между фасадами 2 мм (по 4 мм между парами — по стандарту).
- [ ] Корпус ящика: боковины/дно/задняя/передняя; дно вкладное.

## Двери
- [ ] Накладные, по одной на отделение.
- [ ] Зазоры 4 мм между дверями, 2 мм по краям.
- [ ] Ход открывания не задевает ящики/фасады.

## Финал
- [ ] `basis_model_summary`: имена, размеры, кромки, количество совпадают.
- [ ] Визуальный осмотр (3D, тонирование).
- [ ] «Анализ модели» в БАЗИС — без ошибок.
- [ ] Пользователь подтвердил сохранение модели.
