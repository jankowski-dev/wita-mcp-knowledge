# AKS: 3D-модели и база для БАЗИС-Мебельщик

Источник: https://aks.by/help/biblioteka-3d-modeley/ (раздел «База 3D моделей
для Базис-Мебельщик»). Скачанные архивы класть в библиотеку фурнитуры БАЗИС
(пути согласуются с пользователем).

## Ключевой архив

- **База материалов — Фурнитура АКС Мебель**
  `https://aks.by/prochee/3d-model-bazis/База%20материалов%20-%20Фурнитура%20АКС%20Мебель.rar`
  Готовая база фурнитуры AKS для импорта в БАЗИС (подтвердить состав и порядок
  импорта у пользователя/поддержки AKS).

## Замечания

- Архивы .rar — распаковка на Windows (7-Zip/WinRAR), содержимое .f3d для
  БАЗИС; перед массовой установкой проверять одну модель через
  `open_furniture` + `mount_furniture` на черновой панели.
- Скачивание и размещение в библиотеке — согласовать с пользователем.
