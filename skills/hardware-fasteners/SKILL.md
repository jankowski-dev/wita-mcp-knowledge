# Фурнитура, крепёж и присадка

Основа производства пользователя: **GTV и AKS** (Blum — эталон цифр).
Порядок Mount и правила WITA — в `furniture-design`; здесь — размеры и схемы.
**Модели и готовая база фурнитуры AKS для БАЗИС:** `references/aks-models.md`.
Помечено **[ПРОВЕРИТЬ]** — сверить с каталогами/производством (каталоги
загружаются в RAG: GTV-энциклопедия 2018, GTV-направляющие 2024, Blum 2024-25).

## 1. System 32 — база присадки

- Шаг отверстий **32 мм** по ширине, длине и в торце детали.
- Первый ряд от лицевой кромки — **37 мм**, далее кратно 32.
- Ø5 мм — основные отверстия в пласти (полкодержатели, планки петель, стяжки).
- Исключение — присадка петель (свои размеры, см. ниже).
- Правило: правые/левые детали взаимозаменяемы за счёт симметричной присадки.

## 2. Петли

| Параметр | Значение |
|---|---|
| Чашка | Ø35 мм, глубина **12 мм** (GTV, подтверждено каталогом 2018) |
| Центр чашки от торца двери | **≈21.5 мм** (K = **≈4 мм** от края чашки — рабочий трафарет WITA; по каталогу GTV K=3–5) |
| Отверстия чашки, межцентровое | **45 мм** (GTV CLIP-ON/ECHC); 48 мм — часть AKS; у Blum по серии |
| Ответная планка | H=0 (база), H=2/4/6 — регулировка по высоте |
| Присадка планки | **A=37 мм** от края боковины (накладная, GTV); также 32 под System 32 |
| Типы | накладная / полунакладная / вкладная |
| Углы | 110° стандарт; 165° — угловые/широкое открывание |

- Количество петель на дверь (по высоте/весу) **[ПРОВЕРИТЬ]**:
  до 600 мм — 2; 600–900 — 3; 900–1200 — 4; 1200–1600 — 5.
- Доводчик: встроенный (Blumotion/Soft-close) или накладной.
- Стеклянные фасады — специальные петли (чашка под стекло), не путать с ЛДСП.

## 3. Направляющие ящиков

| Тип | Зазор на сторону | Нагрузка | Примечание |
|---|---|---|---|
| Шариковые (телескоп) — **основной** | 13 мм (ящик = проём − 26) | 25–45 кг | Полное выдвижение |
| Скрытые (undermount) — **GTV** | по каталогу | 25–40 кг | Дно в паз; плавнее |
| Роликовые | ~12.5–13 мм | 20–25 кг | Бюджет; длина 250–500 |

- Длина направляющей = глубина корпуса − (10–20) мм; ящик короче направляющей
  на толщину фасада/зазоры.
- Зазор между фасадами ящиков — **2–3 мм**.
- Крепление к боковине — по System 32 (шаг 32) или по схеме производителя.

## 4. Крепёж корпуса

| Крепёж | Отверстия | Где применять |
|---|---|---|
| Конфирмат 6.4×50 | Ø5 в пласть + Ø7 в торец (подтверждено производством WITA) | Основное соединение корпуса |
| Эксцентрик | Ø15 гнездо + Ø5 стяжка | Разборные соединения, стяжки |
| Минификс | Ø5 пласть + Ø8 торец | Быстрый монтаж полок/связей |
| Шкант Ø8×30(35) | Ø8 + клей | Фиксация, усиление стыков |
| Полкодержатель Ø5 | Ø5, шаг 32 | Полки на System 32 |

- Отступы конфирмата от кромок: 8–10 мм от края, 30–40 мм от торца
  **[ПРОВЕРИТЬ]** под конкретную оснастку производства.
- Порядок Mount (WITA): горизонтальная деталь (полка/дно) — **первой**,
  крепёж через боковину/перегородку в торец.

## 5. Прочее

- Ручки: межцентровое расстояние под System 32; рейлинги/профиль-ручка.
- Газлифты/подъёмники: по весу фасада, схемы производителя.
- Push-to-open: петли/направляющие с нажимом (без ручек).
- Угловые шкафы: угловые петли 90°/135°, карусели — по каталогу.

## 6. Связь с WITA MCP

- `open_furniture` + `mount_furniture` (plane/between) + `mount_scheme` —
  установка фурнитуры по координатам панели (panel-local).
- `add_butt(material: "<полное имя>")` — кромка из имени (v0.6.2), пикер не
  нужен.
- `holes_info` — контроль отверстий, созданных фурнитурой.
- Присадку по System 32 пока делаем фурнитурой (петли/направляющие создают
  отверстия); отдельные сверления — через `add_cut`/руками.

## 6a. Спецификация фурнитуры

- Артикулы у пользователя отсутствуют — спецификация ведётся по
  **наименованию + серии + производителю** (GTV/AKS), с размерами/количеством.
- Если позже появится список артикулов — добавляем колонку «Артикул».

## 7. Чек-лист узла

1. Тип петли соответствует двери (накладная/вкладная/угол).
2. Чашка/планка/межцентровые сверены с каталогом серии.
3. Количество петель по высоте/весу.
4. Направляющая по глубине корпуса; зазор 13 мм/сторона учтён.
5. Крепёж выбран по разборности (конфирмат/эксцентрик/минификс).
6. Порядок Mount соблюдён (горизонталь первой).
