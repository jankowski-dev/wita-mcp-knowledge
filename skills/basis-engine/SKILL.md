# Уроки движка БАЗИС (2022.12.21)

## Среда

- Исходники скриптов **только ASCII** (движок читает CP1251); русские строки —
  через `\uXXXX`-экранирование в рантайме.
  Контроль после правок:
  `python -c "print(sum(1 for b in open(f,'rb').read() if b>127))"` → 0.
- Старое API (v5-модулей нет). Доступны: `Model`, `Action`, `NewButtonInput`,
  `NewButtMaterialInput`, `AddFrontPanel/AddHorizPanel/AddVertPanel`,
  `DeleteObject`, `OpenFurniture`, `BeginBlock/EndBlock`, `require('fs')`, `system`.
- `require()` — Node-набор (fs, path, http, child_process…), COM работает.

## Живучесть

- Скрипт, завершившийся после `setInterval`, **теряет таймеры** (~3 мин → смерть).
- `Action.Continue()` **не блокирует**, а разрешает прерывания после тела скрипта;
  сессия с `setInterval` живёт часами. Это основа авто-режима worker'а.
- `$move` вне активных action-режимов не вызывается — триггером быть не может.
- Сессию убивают: ESC, запуск другого скрипта, перезапуск БАЗИС, выбор в пикере
  `NewButtMaterialInput`.
- Синтетический ввод (SendKeys/клики/PostMessage/UIA) движок игнорирует —
  меню автоматизировать извне нельзя.

## Модель и Commit

- Созданные объекты = «новые объекты скрипта»: в дерево попадают после
  `Action.Commit()` (или завершения скрипта).
- Свойства задавать **до** коммита: после коммита обёртка «перерождается»,
  присвоения уходят в никуда.
- Чтение: `Model.Count`, `Model.Objects[i]`, у панели —
  `ContourWidth/ContourHeight/Thickness/Butts.Count/MaterialName`, у объекта —
  `Position`, `GMax`, `GMin`.

## Ориентация панелей

- `AddFrontPanel(x1,y1,x2,y2,z)` — плоскость XY.
- `AddHorizPanel(x1,z1,x2,z2,y)` — плоскость XZ, высота y.
- `AddVertPanel(z1,y1,z2,y2,x)` — плоскость YZ, положение x.

## Кромка

- `panel.AddButt(material, elem)`, elem 0..3 — элементы контура против часовой
  стрелки от начала координат.
- Материал — **объект** `NewButtMaterialInput`; строка с именем молча игнорируется.
- Дефолт пикера — первая кромка базы: достаточно для программной оклейки.

## Фурнитура и крепёж

- `OpenFurniture(path.f3d)` → `Mount(panel1, panel2, x, y, z)` — между панелями;
  `Mount1(panel, x, y, z, angle)` — на плоскость.
- Координаты Mount — глобальные мм; ось = нормаль стыка.
- **Порядок панелей влияет на центровку**: полка первой — по центру толщины;
  обратный порядок — на кромку.
- Петли: `Mount(боковина, дверь, 32, высота, 0)` (образец «Редактируемая тумба.js»).
- `MountScheme` — схема крепежа на стык, **не петли**.
- Кириллические пути `.f3d` через JSON проходят без искажений.

## Производительность

- Панели/кромка/конфирматы — 0–3 мс; сложная фурнитура — до 3.5 с (первое открытие).
- Батч 100+ команд за один тик — норма.
