# WITA MCP Knowledge — скиллы для проектирования в БАЗИС

База знаний ИИ-агента для работы с САПР БАЗИС-Мебельщик через
[WITA MCP Server](https://github.com/jankowski-dev/wita-mcp-server).

Скиллы — это «правила и процедуры», которые агент загружает по требованию.
Отдельно от кода: переносятся на любой ПК одним `git clone` + строка в конфиге.

## Скиллы

| ID | Когда применяется |
|---|---|
| `furniture-design` | проектирование/проверка мебели: секции, корпус, ХДФ в пазе, ящики, двери, петли |
| `basis-mcp` | работа с MCP-сервером: статус worker'а, операции, восстановление |
| `basis-engine` | разработка скриптов и отладка: ASCII/CP1251, Continue, Commit, Mount |
| `wardrobe-generator` | генерация шкафа по параметрам: формулы и порядок операций |

## Установка

### Вариант 1 — подключить каталог (рекомендуется)

Склонируйте репозиторий в любое место и добавьте в `opencode.json`:

```jsonc
{
  "skills": ["C:\\Tools\\wita-mcp-knowledge\\skills"]
}
```

Относительный путь отсчитывается от рабочей директории OpenCode;
`~/` — от домашней. Обновления: `git pull`.

### Вариант 2 — глобально на ПК

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

Копирует скиллы в `~/.config/opencode/skills` — доступны во всех проектах.

## Использование

- Агент сам подгружает скилл, когда задача совпадает с описанием.
- Явно: упомяните `@furniture-design` в промпте.

## Связка с RAG (фаза 2)

Планируется `kb/` + локальный MCP-сервер `kb_search` для поиска по библиотеке
(каталоги фурнитуры, нормативы, разборы проектов). Скиллы останутся «правилами»,
RAG — «фактами».
